## What a placeholder is not

A file in this directory with the intended filename and a description of what
it would show is **not** evidence. It is a fabrication risk: it looks like proof
to anyone scanning the tree, and it invites someone to fill in the blanks later
without performing the review. Until an artifact genuinely exists, the register
and the milestone documentation are the record.
